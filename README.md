# magicsquare 幻方

终端里的幻方（Magic Square）小玩具：生成 + 验证。

## 玩法

```bash
python3 -m magicsquare            # 生成 3×3 幻方
python3 -m magicsquare --n 5      # 生成 5×5 幻方
python3 -m magicsquare --n 4      # 生成 4×4 幻方
printf '8 1 6\n3 5 7\n4 9 2\n' | python3 -m magicsquare --check   # 从 stdin 验证
python3 -m magicsquare --check 方阵.txt   # 从文件验证（空格或逗号分隔）
```

输出示例（`--n 5`）：

```
幻方 5×5，幻和 = 65：

17 24  1  8 15
23  5  7 14 16
 4  6 13 20 22
10 12 19 21  3
11 18 25  2  9
```

## 构造方法

- **奇数阶（3、5、7…）**：暹罗法（Siamese method）——从顶行中间放 1，右上走，撞车走正下方。
- **4 的倍数阶（4、8…）**：对角线交换法——顺排 1..n²，对角线上的数取补（n²+1−x）。
- **4k+2 阶（6、10…）**：不支持，LUX 方法超出"小巧"范围，会明确报错。

幻和公式：n(n²+1)/2（3→15、5→65、7→175）。

## 验证规则

`--check` 判定标准幻方：

1. 数字恰为 1..n² 的排列（重复/缺失都判非法）；
2. 每行、每列、两条对角线之和都等于幻和。

合法返回 exit 0，非法返回 exit 1，参数/读取错误返回 exit 2。

## 真实验证记录

- `py_compile` 通过（Python 3.10+，纯标准库 argparse/sys）。
- 暹罗法 3/5/7 阶、`doubly_even` 4 阶：生成结果全部通过 `check()`，且为 1..n² 排列。
- 洛书 `[[8,1,6],[3,5,7],[4,9,2]]` 验证通过；交换两格→判列和非法；改出重复数字→判排列非法。
- CLI 端到端：`--n 5`、`--n 4`、`--check`（stdin/文件/逗号分隔）、`--n 6` 报错 exit 2。

## 已知局限

- 只做标准幻方（1..n² 全排列），不支持泛幻方/最完美幻方等变体。
- 4k+2 阶不支持（LUX 方法不在小巧范围内）。
- 无交互式填格玩法，只有"生成+验证"。
- 数字对齐用等宽空格，终端需等宽字体。
